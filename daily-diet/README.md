# 스킬을 만든 이유

매일 하는 식단 관리에는 소소하게 귀찮은 불편함이 따릅니다. 음식별 칼로리 및 영양 정보를 직접 검색하고, AI에게 1500kcal, 5:3:2라는 수치를 매번 입력한 후 분석/평가해달라고 하는 번거로움입니다. 이 스킬을 사용 시 식단만 입력하면, 스킬이 자동으로 목표 칼로리 및 영양소 비율로 목표 달성 여부를 계산하여 한 줄 피드백 형식으로 명확하게 정리해 줍니다.
